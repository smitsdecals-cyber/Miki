Convention de nommage des calques

Dans Illustrator, ouvrez la palette Calques et renommez chaque calque/groupe selon le type de modification souhaité :

  • color_xxx — zone dont la couleur peut être modifiée
  • texte_xxx — texte modifiable (cliquer + saisir)
  • logo_xxx — emplacement de logo (drag & drop)

À l'export Fichier → Exporter sous… → SVG, cochez :

  • Styling : Presentation Attributes
  • Object IDs : Layer Names
  • Decimal : 2
  • Minify / Responsive : au choix

Le nom du calque devient ainsi l'id du <g> et le configurateur l'expose automatiquement.
